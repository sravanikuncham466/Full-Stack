# Laundry Mart Login Page

## Description
This project is a responsive login page built using HTML and Flexbox.

## Features
- split screen layout using flexbox
- login form with 
   - email input
   - password input
   - forgot password link
   - login button
   - register link

## Technologies used
- HTML
- CSS

## How to run project
- Download or clone the repository
- open the folder
- Double click on index.html or open it using any web browser
