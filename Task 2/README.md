#Laundry wallah / laundry mart

## Description
This project is a simple HTML webpage for a laundry service called Laundry wallah/ Laundry Mart. It Demonstrates basic HTML structure and includes multiple sections such as header, about, services, price list, booking form, and footer.

## Features
- Header with welcome message.
- About scetion describing the service
- Image section displaying a laundry image
- services list using unordered list
- Price list displayed using a table.
- Booking form with input fields ( Name, Email, Phone) 
- Footer with contact information

## files
index.html
README.md

## How to run
1. Download or clone the project folder
2. open the folder.
3. locate the file index.html
4. double click the file.
   or
   right click -> open with any web browser (chrome, edge)
5. The webpage will open and display all sections.
