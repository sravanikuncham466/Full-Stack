Task 3: CSS Selectors

# project description

This project demonstrates the usage of different CSS selectors to style HTML elements.
The objective of this task is to understand how element selector, class selectors, ID selectors, descendent selectors, and pseudo class selectors work in css.

The project is created using HTML and CSS without inline CSS.

CSS

# CSS concepts implemented
# 1. Element selector
The `body` and `p` element selectors are used to apply styles directly to HTML elements.
# 2. Class selector
The .head class selector is used to apply the same styling to multiple heading elements.
# 3. ID selector
ID selectors are used to apply unique styles to specific elements.
# 4. Descendent selector
A descendant selector is used to style specific elements inside another element.
# 5. Span Element selector
The span element is used to style specific words without affecting the entire paragraph or link.
# 6. Anchor tag styling
Links are styled without using any class or id.
Implemented:
Removed underline from links
Changed link colors
# 7. Pseudo class selector:
The :nth-child() selector is used to style specific list items.
