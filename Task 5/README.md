# Project description
This project is a simple web page that implements the Hero section of a laundry  Service website using HTML and CSS.


The Webpage includes:
- Navigation bar
- Hero section
- Responsive layout using inline-block

# Navigation bar
- logo on the left
- navigation links
   - Home
   - Services
   - About Us
   - Contact Us
- Username on the right

# Hero Section
- left section contains: Heading, Description, Book a service today button
- Right section contains: laundry related image

# Technologies used
- HTML5
- CSS
